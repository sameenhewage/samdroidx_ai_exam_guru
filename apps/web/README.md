# AI Exam Guru Admin Web

The Next.js application hosts the Priority 1 Admin Content Studio. Priority 2 student functionality remains blocked until P10 is DONE.

Run commands from the repository root:

```bash
npm ci
npm run dev --prefix apps/web
npm run lint --prefix apps/web
npm run test:coverage --prefix apps/web
npm run build --prefix apps/web
```

Use Node.js 24.19 and npm 11.17, or start the complete pinned Docker stack as documented in the root `README.md`.
