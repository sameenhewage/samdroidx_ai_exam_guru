# D9 — Legacy Source-Reading Cutover

## Mission

Complete the D9 cutover so **exactly one source architecture ships**.

The authoritative architecture is D17 + D18:

```
Immutable source
→ deterministic 300-DPI render
→ deterministic layout
→ canonical crop for EVERY region
→ executing agent directly visually reads the exact canonical crop
→ primary transcript JSON
→ schema/checksum/bbox seal
→ deterministic validators
→ Machine Candidate = primary text
→ human review
→ Verified Source Content
→ only then knowledge / embeddings / RAG / generation
```

There is **no OCR stage in the active Source V2 reading path**.

D18 source kinds remain:
- TEXT_ONLY
- VISUAL_ONLY
- VISUAL_WITH_TEXT
- DECORATIVE
- UNDECIDED

Do not redesign D17/D18.
Do not begin vectorization.
Do not begin AI image-generation work.
Do not begin broad corpus migration.

## Non-negotiable invariants

Preserve:
- deterministic rendering
- deterministic layout
- canonical crops
- source identity/checksums
- bbox provenance
- human verification
- Source V2 persistence and append-only review history
- D18 source kinds
- verified-source gate
- generic alignment helpers intentionally ported into V2
- **all historical database migrations**

Historical evidence may remain:
- `docs/source-v2/BENCHMARK_READERS.md`
- `_archive/`
- historical DECISIONS sections

Historical evidence must not be wired into active runtime.

Original source text must never be translated, normalized, corrected, or regenerated by code.

## Phase 2 — Classify what may be removed

A file/config/dependency/test is removable only when the Phase 1 evidence proves it belongs exclusively to the old V1/source-reader architecture and is not required by:
- Source V2
- generic rendering/layout/crop/alignment utilities used by V2
- persistence
- review history
- D18
- source gates
- historical migrations

If a legacy module contains a generic helper that V2 still needs:
1. move/port only that generic helper to an appropriate V2-neutral location,
2. update active imports,
3. prove behavior with tests,
4. then remove the legacy container module.

Do not retain entire legacy stacks “just in case.”
